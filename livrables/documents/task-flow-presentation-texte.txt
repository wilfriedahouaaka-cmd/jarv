L'essence du projet
Task Flow est une application web statique de productivité personnelle. Elle permet d'organiser ses tâches, de
définir des priorités et de suivre sa progression entièrement dans le navigateur, sans aucun serveur ni
inscription.
L'idée centrale
Offrir un outil de gestion de tâches simple, clair et respectueux de la vie privée. Toutes les données restent
sur l'appareil de l'utilisateur (localStorage). Aucune donnée n'est jamais envoyée sur internet.

Problème & Solution
Le constat
• La plupart des applications de tâches demandent un compte et envoient les données sur des serveurs.
• Elles sont souvent trop complexes ou chargées de fonctionnalités inutiles.
• L'utilisateur perd le contrôle de ses propres informations personnelles.
La réponse de Task Flow
Une application légère, rapide et privée qui se concentre uniquement sur l'essentiel : créer, organiser et
terminer des tâches, tout en offrant un tableau de bord de progression et un petit profil personnel.
« Transformez vos tâches en progrès visibles. »

Task Flow — Présentation 4 / 8
Fonctionnalités principales
• Création de tâches — Nom, description, catégorie, priorité, date et moment de la journée
• Liste temporaire — Préparez plusieurs tâches avant de les enregistrer définitivement
• Filtres intelligents — Toutes / Affaires / Terminées / Prioritaires
• Tableau de bord — Statistiques de progression, compteurs et vue d'ensemble
• Profil personnel — Photo ou initiales + historique des actions
• Thème clair / sombre — Adaptation visuelle selon les préférences
• Responsive — Fonctionne parfaitement sur téléphone et ordinateur
• 100 % local — Stockage via localStorage — aucune donnée ne quitte l'appareil

========== PAGE 6 ==========
Task Flow — Présentation 6 / 8
Architecture technique
Application 100 % statique : HTML + CSS + JavaScript pur. Aucun backend, aucun framework lourd, aucune
base de données distante.
Frontend HTML5 sémantique, CSS moderne (variables, flex/grid), JavaScript vanilla
Stockage localStorage (profil, tâches, historique, thème, liste temporaire)
Hébergement Compatible GitHub Pages, Netlify, Vercel ou tout serveur de fichiers statiques
Responsive Design adaptatif mobile-first avec menu hamburger et grilles fluides
Idéal pour un prototype éducatif, un outil personnel ou une démonstration de frontend moderne sans backend.
